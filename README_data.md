
# DOKUMENTASI SUMBER DATA
## INDONESIA ECONOMIC INTELLIGENCE DASHBOARD

Dokumen ini digunakan untuk mencatat seluruh sumber data
yang digunakan dalam proyek analisis kondisi ekonomi Indonesia.

## 1. DATA TERBUKA RESMI

Sumber:
- BPS: https://www.bps.go.id
- Bank Indonesia: https://www.bi.go.id
- OJK: https://www.ojk.go.id
- Kementerian Keuangan: https://www.kemenkeu.go.id

Variabel:
- Pertumbuhan PDB
- Inflasi
- Pengangguran
- Nilai tukar
- Suku bunga
- Kemiskinan

Status: Menunggu pengumpulan data.

## 2. DATASET BERLABEL

Sumber:
- Kaggle
- Portal dataset publik lainnya.

Kriteria:
- Memiliki variabel ekonomi.
- Memiliki label atau kategori.
- Memiliki dokumentasi.
- Memiliki sumber yang dapat diverifikasi.

Variabel dan label akan dicatat setelah dataset dipilih.

Status: Menunggu pemilihan dataset.

## 3. TEKS PUBLIK MELALUI API

Sumber yang direncanakan:
- GDELT DOC API.
- API berita publik lain yang dapat diakses.

Kata kunci:
- Ekonomi Indonesia.
- Inflasi Indonesia.
- Rupiah.
- Investasi.
- Pengangguran.
- Pertumbuhan ekonomi.

Variabel:
- Tanggal publikasi.
- Judul berita.
- Isi atau ringkasan berita.
- Sumber berita.
- Sentimen.

Status: Menunggu pengambilan data API.

## 4. DATA DARI DOKUMEN

Dokumen yang direncanakan:
- Laporan Perekonomian Indonesia.
- Laporan Kebijakan Moneter.
- Laporan APBN KiTa.
- Publikasi ekonomi BPS.

Informasi yang diekstraksi:
- Indikator ekonomi.
- Periode data.
- Nilai indikator.
- Penjelasan dan analisis.
- Nomor halaman dokumen.

Status: Menunggu pengumpulan dokumen.

## 5. VALIDASI DATA

Setiap sumber akan diperiksa berdasarkan:
- Keaslian sumber.
- Periode pengamatan.
- Kelengkapan data.
- Konsistensi satuan.
- Kesesuaian variabel.
- Kemungkinan duplikasi.

## 6. CATATAN

Data mentah tidak boleh diubah.
Setiap proses pembersihan dan transformasi harus
didokumentasikan agar analisis dapat direproduksi.
