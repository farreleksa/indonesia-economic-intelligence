## Analisis Kondisi Ekonomi Indonesia Berbasis Data Science

### 1. DESKRIPSI PROYEK

Indonesia Economic Intelligence Dashboard merupakan proyek
Lab Sains Data yang bertujuan menganalisis kondisi ekonomi
Indonesia melalui integrasi empat jenis data menggunakan
Python, AI, dan visualisasi interaktif.

Proyek ini berorientasi pada pengambilan keputusan berbasis
data (Data-Driven Decision Making).

### 2. TUJUAN PROYEK

1. Mengidentifikasi perkembangan indikator ekonomi Indonesia.
2. Menganalisis tren dan perubahan kondisi ekonomi.
3. Mengintegrasikan empat jenis sumber data.
4. Mengidentifikasi indikator dan sektor yang memerlukan
   perhatian lebih lanjut.
5. Menghasilkan rekomendasi berdasarkan hasil analisis data.

### 3. KEPUTUSAN YANG INGIN DIHASILKAN

Mengidentifikasi indikator ekonomi yang menunjukkan tekanan
dan menentukan aspek ekonomi yang perlu mendapatkan
perhatian berdasarkan bukti dari berbagai sumber data.

### 4. EMPAT JENIS DATA

**A. Data Terbuka Resmi**
- Badan Pusat Statistik (BPS)
- Bank Indonesia (BI)
- Otoritas Jasa Keuangan (OJK)
- Kementerian Keuangan

**B. Dataset Berlabel**
- Dataset ekonomi dengan kategori atau label yang jelas.
- Digunakan untuk analisis klasifikasi kondisi ekonomi.

**C. Teks Publik melalui API**
- Berita ekonomi Indonesia.
- Informasi inflasi, investasi, rupiah, dan ketenagakerjaan.
- Digunakan untuk analisis sentimen dan topik.

**D. Data dari Dokumen**
- Laporan ekonomi BPS.
- Laporan Bank Indonesia.
- Laporan APBN KiTa.
- Digunakan untuk ekstraksi informasi dari dokumen PDF.

### 5. METODE ANALISIS

1. Data collection.
2. Data cleaning.
3. Data integration.
4. Exploratory Data Analysis (EDA).
5. Data classification.
6. Text and sentiment analysis.
7. Data visualization.
8. Decision recommendation.

### 6. TEKNOLOGI YANG DIGUNAKAN

- GitHub: dokumentasi dan penyimpanan proyek.
- Harness: instruksi dan pengelolaan proses kerja AI.
- Python: pengolahan dan analisis data.
- Pandas dan NumPy: manipulasi data.
- Matplotlib dan Plotly: visualisasi.
- Streamlit: dashboard interaktif.

### 7. OUTPUT PROYEK

- Dataset dari empat jenis sumber data.
- Notebook analisis Python.
- Dokumentasi sumber data.
- Dashboard interaktif.
- Memo keputusan.
- Presentasi hasil analisis.
